# Imágenes de pulseras

Coloque aquí los PNG transparentes de las pulseras reales:

- `black.png` → pulsera negra
- `red.png` → pulsera roja

Recomendado:
- Formato PNG con fondo transparente
- Proporción aprox. 4:3, 1200×900 px
- La zona de la placa centrada para que el grabado se sitúe encima

Mientras estos archivos no existan, el configurador renderizará automáticamente
una representación SVG estilizada del mismo color para no romper la UI.
